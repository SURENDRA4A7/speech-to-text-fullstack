# 🎤 Speech-to-Text AI

A modern Full Stack AI-powered Speech-to-Text Application built using React, TypeScript, Node.js, Express.js, MySQL, WebSockets, and Google Gemini AI. The application captures speech, converts it into text, stores transcripts in a cloud database, and provides transcript history with CRUD operations. It is designed for scalability with future AI-powered multilingual translation and summarization features.

- 🎤 Real-time Speech-to-Text
- 💾 Save transcripts to MySQL

- ✏️ Edit transcripts

- ⚡ REST API using Express.js
- 🔌 WebSocket integration
- 🤖 Gemini AI integration foundation
